# Triage labels

Use this mapping when an engineering skill refers to a triage role.

| Triage role       | GitHub label      | Meaning                                 |
| ----------------- | ----------------- | --------------------------------------- |
| `needs-triage`    | `needs-triage`    | Awaiting maintainer review              |
| `needs-info`      | `needs-info`      | Waiting for details from the reporter   |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent  |
| `ready-for-human` | `ready-for-human` | Requires human implementation           |
| `wontfix`         | `wontfix`         | Closed with no implementation planned   |
