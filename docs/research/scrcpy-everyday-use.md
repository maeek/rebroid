# Everyday scrcpy features for the Rebroid viewer

Rebroid already bundles scrcpy 5.0.1. These proposals concern the browser viewer and its authorized device operations. The priorities reflect expected everyday use and how much existing code Rebroid can reuse. [Sidecar image](../../apps/display-sidecar/Dockerfile) · [Upstream release](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1)

1. **Paste straight into the focused Android field.** A user copying an address or a paragraph should be able to focus the device and press Ctrl+V or Cmd+V once. Rebroid already relays keyboard events and offers explicit clipboard transfers. Its scrcpy encoder sets the paste flag to zero. Let the browser deliver the user's paste event, send its plain text once, and request Android paste on the active display. Require both clipboard and control grants for the combined action. Keep the manual clipboard form available. On external phones, the gesture should transfer only the text the user chose to paste. [Upstream paste behavior](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/control.md#copy-paste) · [Keyboard relay](../../apps/web/src/features/applications/viewer/player/viewer-keyboard-relay.ts) · [Clipboard encoder](../../apps/display-sidecar/src/modules/scrcpy/scrcpy-control-codec.ts) · [External viewer controls](../../apps/web/src/features/applications/pages/external-viewer/viewer-controls.tsx)

2. **Open Notifications in one action.** Checking a download or an incoming message currently takes a swipe from the top edge. The managed toolbar already has Quick settings and Collapse panels. Add Notifications beside them on the main display, with the same device-control permission. Upstream defines separate messages for notifications, settings and collapse. Add the notification action to Rebroid’s shared command list and scrcpy encoder, and map it in the Direct ADB fallback. The verified external viewer could expose the same action. A focused-viewer shortcut can call that command and show its binding in the tooltip. [Upstream shortcuts](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/shortcuts.md) · [Upstream messages](https://github.com/Genymobile/scrcpy/blob/v5.0.1/server/src/main/java/com/genymobile/scrcpy/control/ControlMessage.java) · [Toolbar](../../apps/web/src/features/applications/viewer/display/viewer-control-bar/commands/command-groups.tsx) · [Shared actions](../../packages/android-application-core/src/viewer-control.ts) · [ADB fallback](../../apps/display-sidecar/src/modules/adb/adb.service.ts)

3. **Drop a document or image onto a managed viewer.** Show “Upload to Downloads” while dragging, then reuse the Files upload queue for progress, cancellation and filename conflicts. Users can immediately open the uploaded file in Android. Upstream also asks Android to scan successful uploads so media pickers can find new images. Verify picker visibility for the managed upload path before promising it. Keep APK installation an explicit, separately authorized action. External devices currently lack file transfer, so this fits managed devices first. [Upstream file drop](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/control.md#file-drop) · [Upload queue](../../apps/web/src/features/applications/viewer/tools/runtime-tools-panel/files/use-runtime-file-uploads.ts) · [File permissions](../web-security.md) · [Device capabilities](../operator-console.md#workflow-device-steps)

4. **Open an Android app by name from the viewer.** A managed viewer could offer an app picker for people who repeatedly switch between a browser, Settings and an app under test. Upstream lists installed apps and launches a selected package. Rebroid already has package-ID discovery and launch in workflows. A viewer action could reuse the device operations, add launchable app labels on demand, and launch the exact ID with one click. Verified external devices already support explicit package launch, so an initial version could accept a known package ID there. Browsing a phone’s installed apps would need an explicit inventory capability. [Upstream app selection](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/device.md#start-android-app) · [Managed package operations](../../apps/orchestrator/src/automations/commands/android-device-package-text-automation-commands.ts) · [External adapter](../../apps/orchestrator/src/android-apps/external/devices/external-automation-device.service.ts)

5. **Desktop mouse navigation.** Offer scrcpy’s right-click for Back and middle-click for Home inside the active viewer. The touch handler currently accepts only the primary button. Dispatch the existing navigation commands once per click, consume the browser context menu or autoscroll only over the interactive Android surface, and list the bindings alongside the Ctrl-drag gesture. This lets someone browse a device one-handed without moving between the app and toolbar. [Upstream mouse bindings](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/mouse.md#mouse-bindings) · [Viewer pointer handling](../../apps/display-sidecar/src/modules/display/viewer/src/touch-input.ts)

**Open a link on Android.** Let the user paste an invite or map link and choose the managed device that should open it. Validate the HTTP or HTTPS URL on the server and dispatch Android’s `ACTION_VIEW` with that URL as data. Android can open the associated app or its default browser. Report when the device lacks a handler. A verified external phone would need a corresponding attachment-scoped broker operation. [Android web intents](https://developer.android.com/guide/components/intents-common#Browser) · [External device operations](../operator-console.md#external-android-devices)

Rebroid already handles touch pinch and rotation, Ctrl-drag with a mouse, trackpad scrolling, and stream size, frame rate and bitrate settings. Those controls are candidates for a shortcut guide.
