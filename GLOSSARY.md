# Rebroid

## Account access

**Account session**

One browser sign-in to a Rebroid account. Tabs that share the browser's sign-in cookie share the account session.

**Display session**

A viewer grant for an Android runtime display. An account can open viewers from multiple account sessions.

## Android application profiles

**Profile storage identity**

The volume name associated with an Android application's profile. Distinct saved profile names can refer to the same volume, so deleting one of those profiles could affect the data used by another.
